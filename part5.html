Mini Project: Interactive Accordion Menu

Built with jQuery selectors and smooth slide animations (.slideUp, .slideDown).

1. What is jQuery? +
jQuery is a fast, small, and feature-rich JavaScript library. It makes HTML document traversal, manipulation, event handling, and animation much simpler with an easy-to-use API.
2. Why use $(document).ready()? +
The $(document).ready() event ensures that all DOM elements are fully loaded and accessible before any jQuery code executes, preventing errors when trying to select non-existent nodes.
3. How does .animate() work? +
The .animate() method performs custom animations on numeric CSS properties such as width, height, opacity, left, and top. Elements must have position: relative, absolute, or fixed to animate their coordinates.
4. How do jQuery Effects improve UX? +
Methods like .fadeIn(), .fadeOut(), and .slideToggle() provide smooth visual feedback for user interactions, avoiding abrupt screen changes and improving page usability.
